# suncut — 本地 AI 短剧流水线 + 网页工作台

一句话故事梗概 → 可发布短剧(竖版/横版,1080p/720p/480p)的全自动本地流水线。
**八个 agent 分工**(招聘/服化道/编剧/分镜/导演/审片/配音师/制片),本地 Qwen-Image-2.1 出图 +
Sol-H3(MiniMax-H3)出视频,LLM 走智谱 GLM,配音走 edge-tts;支持 CLI 全自动与**网页工作台人工质控**两种开拍方式。

```
浏览器工作台(可选,质控位)            CLI 全自动
        │ REST + WebSocket                 │
        ▼                                  ▼
   sdapi :8620 (FastAPI)              python3 -m sd produce
        └──────────► sd/ 八 agent 领域包(共用,零改动)◄──────────┘
                        │
        ┌───────────────┼────────────────┬─────────────┐
        ▼               ▼                ▼             ▼
  Sol-H3 infer(docker) ComfyUI :8189  智谱 GLM      edge-tts
  草稿视频 ~70-120s/镜  母版超分/14步重生成  编剧/评审/审片VLM  台词/旁白配音
```

## 1. 环境要求与一次性安装

**机器**:DGX Spark(GB10)或同级 CUDA 环境;磁盘 ≥50G 空闲;内存 ≥40G。

**前置依赖**(本机已就绪,换机需重装):

| 依赖 | 位置/检查方式 |
|---|---|
| ffmpeg / ffprobe | `ffmpeg -version` |
| docker + Sol-H3-Spark | `~/.zcode/workspace/default/Sana/models/minimax_h3/Sol-H3-Spark/infer.py` |
| ComfyUI(母版/重生成用) | `http://127.0.0.1:8189`,不在时会自动拉起 |
| Qwen-Image-2.1 | `~/models/Qwen-Image-2.1` + `~/venvs/imagegen`(diffusers) |
| 演员库工坊 | `~/桌面/AI角色工坊/素材/<角色>/角色提示词.md` |
| **资产库(道具/场地)** | `~/桌面/短剧资产库/{场地,道具}/*.json`(自动生成,可手编) |


**开拍前体检**(两分钟,查工具/磁盘/内存/GPU/docker/演员库/key/ComfyUI):

```bash
cd ~/Desktop/suncut && python3 -m sd doctor        # 加 --llm 附带 LLM 实测
```

## 3. 工作台使用指导

### 3.1 仪表盘 —— 建项目、选开拍模式

- **＋ 新建项目**:项目名 + **故事梗概一句话** + 镜头数(1 镜≈5秒)+ **固定横屏16:9** + 分辨率(1080p/720p/480p)；竖屏中心裁切已禁用。
- 项目卡显示八阶段进度条、审片通过率、忙碌状态;
- 两种开拍模式:
  - **🎬 全自动**:一次到底,审片不过自动重拍≤2轮,配音后交付,全片约 1-2 小时(4镜);
  - **🧭 分步流水线**:每个 agent 完成后**暂停等你放行**,审片后必停一档——逐段把控质量用这个。

### 3.2 项目工作台 —— 八个 agent 面板

顶部步进器点击切换面板(✓=已完成,⟳=运行中,⏸=待放行);标题旁 🎞 按钮可改横屏分辨率:

| 面板 | 能看什么 | 能做什么 |
|---|---|---|
| ① 招聘 | 选角卡:选角理由/服装备注/角色DNA/三视图 | **🖐 手动选角**(演员卡勾选1-2人)/ 🤖 agent 选;跳演员库补资料 |
| ② 服化道 | 场景DNA(点光源)/音乐块(95BPM)/道具/空镜/**库锁定徽标** | **📦 预选资产**(场地逐字锁定,道具必用);产出自动归档资产库 |
| ③ 编剧 | 标题/一句话/自评四维/**镜次表含台词**/旁白 | ↻重写;下载 SRT(台词+旁白,剪映可导入) |
| ④ 分镜 | 每镜 dd/运镜/seed/lint记录 | **✏️ 编辑 dd**(过 lint 闸,DNA 逐字保留) |
| ⑤ 导演 | 每镜视频+重拍条历史 | **🎥 重拍**(填建议)/💎 14步重生成;看 infer 日志 |
| ⑥ 审片 | 抽帧四宫格/三维分/重拍建议/条历史 | **人工通过 / ⛔ 否决并重拍**(核心质控位) |
| ⑦ 配音师 | 音色分配(按角色气质)/VO 时间表/逐段试听 | **↻ 重新配音**;**🎵 上传 BGM**(全片替换配乐);配音预览试听 |
| ⑧ 制片 | 选条表/成片/封面/制作报告/指标 | **📦 交付**(可勾选📝自动烧字幕);💎 母版超分 |

**质控三板斧**:分步流水线的阶段放行门 → 审片否决(自动带建议发起重拍)→ dd 编辑(下次重拍/重生成即生效)。

### 3.3 演员库 / 资产库 / 任务中心 / 系统

- **演员库**:全员三视图完整度(可开拍/资料不全),`🧩 补三视图`、`🔄 转台参考集`;
- **签约新演员**(库不够用时):
  - `＋ 签约主演`:你写一句招聘要求 → 演员 agent 优化成多张**可编辑人设卡**(秒级,不占 GPU)→ 生成试镜照(约4分钟/人,进**候选区**,对招聘 agent 不可见)→ 看脸选人:重掷/回炉/「签约入库」(三视图+三件套全链约20-30分钟,自动分配 角色X_ 前缀);
  - `＋ 签约群演(批量)`:一次 N 张差异化人设,默认直接全套入库(约13-15分钟/人,挂机档),也可先试镜后勾选;
  - **按名单批量签约(IP 班底)**:`POST /api/audition/sign-cards` 提交既定人设卡名单(≤40 人,单人失败不断链,断点续跑);
    卡可带 `look:"game"` 走**游戏还原外观模式**——发色/瞳色/年龄/人种按设定还原(常规中式审美铁律只作用于默认模式)。示例:`scripts/stardew_cast.py`(星露谷 25 名成年村民);
  - 断点续跑:三视图已存在的候选重提交会跳过生成,无损恢复;
- **🗄 资产库**(道具/场地跨项目复用):`＋ 新增` 手工录入;**服化道 agent 每次产出自动归档**新场景/道具;项目里预选后锁定复用(场景 DNA 逐字进 prompt);
- **任务中心**:全局任务表 + 实时日志,审批门的「放行/取消」也可在这里操作;
- **系统**:doctor 预检、路径/模型配置速览(含资产库/审片VLM/配音TTS)、架构图。

### 3.4 配音/配乐/字幕怎么配合(⑦→⑧ 链路)

1. 编剧写台词(画面拍背影/侧脸,不依赖口型)→ SRT 自动合并台词+旁白;
2. 配音师按角色气质分配 edge-tts 音色,逐段合成全片 VO 轨(时间轴与字幕对齐),产出试听预览;
3. 可选:上传 `bgm.mp3` 全片替换配乐(循环铺底、响度统一);
4. 制片交付时自动**侧链混音**(人声出现处音乐自动压低让路);勾选「📝 自动字幕」则把台词/旁白直接烧进画面(Noto Sans CJK,无乱码);
5. 重拍换条不影响配音(每镜恒 5.04s,时间轴不变,交付时按最新选条重混)。

### 3.5 使用纪律(重要)

- **同一项目同时只跑一个任务**(state 无锁,防覆盖);GPU 任务全局串行(infer 与 ComfyUI 互斥占卡);
- 任务历史落盘 `jobs.jsonl`(含日志尾部60行),服务重启后仍可在任务中心查看;**重启会中断正在跑的任务体**(产物落盘幂等,重提交即续跑;GPU 子进程可能变孤儿继续写文件,重提交会自动等它跑完);
- 生成中的 infer 任务不能中途强杀(按设计走缺镜自愈),取消只在分步流水线的阶段间隙生效。

## 4. CLI 备用速查

```bash
python3 -m sd new <名字> --brief "故事梗概" --shots 4          # 建项目(横屏1080p)
python3 -m sd new <名字> --brief "..." --resolution 720p
python3 -m sd produce <名字>                              # 全自动开拍(含配音)
python3 -m sd review <名字> --force                       # 重审片
python3 -m sd retake <名字> <名字-q2> --advice "建议"      # 单镜重拍
python3 -m sd master <名字>                               # 母版: SPAN×2 超分 CRF14
python3 -m sd regen <名字> <名字-q2> --steps 14           # 终极: 14步重生成(~10min/镜)
python3 -m sd buildrefs <角色名关键字>                     # 演员补三视图
python3 -m sd turntable <角色名关键字>                     # 转台参考集
python3 -m sd metrics <名字> / status [名字] / doctor      # 指标/进度/体检
```

**项目目录结构**(D 轮优化后,新项目自动创建):

```
projects/<名字>/
├── brief.txt / state.json        # 输入与断点状态
├── cast|materials|script|storyboard|generate|dub|review.json   # 各阶段产物(数据库)
├── assets.json                   # 预选的资产库场地/道具
```

## 7. 审片视觉模型怎么选

默认 **glm-4.5v**。A/B 实测(`scripts/vision_ab.py`,18 例 × 双模型 × 双次,以归档双次均值为参照):
glm-4.5v 平均偏差 0.5 分、更稳;**glm-5.3-flash 也支持图片输入**,速度快 ~30%,但偏差略大(约 0.8 分)、个别镜波动 3 分。
结论:**重准确用 4.5v(默认),重速度可切 flash**。切换方式(免改码):

```bash
SD_VISION_MODEL=glm-5.3-flash scripts/sdapi-serve.sh    # 重启生效
```

(glm-5.3 大杯模型不支持图片输入,不要选它做审片。)

## 8. 常见问题

| 现象 | 原因/处理 |
|---|---|
| 提交任务报 409「项目正在跑」 | 同项目单任务纪律;去任务中心看进行中的任务 |
| 生成任务很久没动静 | 看⑤导演面板 infer 日志,或任务中心实时日志;首镜含模型加载较慢 |
| 首次 master/regen 前几分钟无输出 | ComfyUI 自动拉起中(最长 ~5min),之后 ~80s/镜 |
| 审片分和上次不一样 | VLM 单次噪声±4,系统已双次取均值+条历史只升不降,属正常 |
| 配音任务失败/无声 | edge-tts 需联网(微软服务);`~/venvs/sdapi/bin/edge-tts --list-voices` 自检 |
| 字幕没烧上 | 字幕烧录需 `subtitles/*.srt`(老项目用 narration.srt 兜底);重新勾选字幕交付 |
| 重启服务时恰有 GPU 任务在跑 | 任务体被中断但子进程可能仍在出图;重提交同任务会自动等待并复用已产出文件(断点续跑) |
| 健康检查 | `curl :8620/api/health` —— ok/版本/活跃任务数 |
| 换了智谱 key | 直接改 provider_config.json,免重启 |
| 视频进度条拖不动 | 不会发生:媒体网关带 HTTP Range;若发生在反向代理后,检查代理的 range 透传 |
| 改了分辨率没生效 | 已交付过的项目需重新「交付成片」;生成中的视频不受影响 |

## 10. 已知边界(诚实清单)

- 复杂动作是 H3 固有弱项,重拍边际递减,14 步档是当前最优解;
- 单镜≤2 人、群演=0 是硬约束(串脸风险);自动参考图角色略弱于手工参考集;
- 台词是画外音配音(画面拍背影/侧脸/远景),不做对口型;
- 剪映精剪仍可后制:字幕 SRT 可直接导入,配音轨在 audio/ 可单独取用;
- 工作台默认监听 127.0.0.1;`SDAPI_HOST=0.0.0.0` 开局域网前请自知无鉴权。
